# Лимиты реляционной памяти (`system.db.sql`)

SQL-память (SQLite) работает как кэш быстрого доступа, интегрированный напрямую в системный промпт агента (в отличие от RAG, где нужно делать поиск). 

Чтобы системный промпт не переполнялся и не вызывал ошибку `Maximum Context Length Exceeded`, в `settings.yaml` предусмотрены жесткие лимиты на количество одновременно хранимых записей.

Вся архитектура SQL-памяти разделена на 5 когнитивных подсистем. Подробное описание их работы и настроек находится в соответствующих файлах:

1. [Tasks (Матрица Эйзенхауэра)](tasks.md) — Долгосрочное планирование и делегирование.
2. [Mental States (Active CRM)](mental_states.md) — Социальный радар, статусы и отношения.
3. [Drives (Психология)](drives.md) — Внутренняя мотивация и проактивность.
4. [Notes (Оперативная память)](notes.md) — "Стикеры на мониторе" для промежуточных данных.
5. [Personality Traits (Черты личности)](personality_traits.md) — Динамическая адаптация характера.
