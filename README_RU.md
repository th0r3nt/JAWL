# JAWL (Just A While Loop)

**JAWL** — это асинхронный фреймворк для создания автономных ИИ-агентов непрерывного цикла (Event-Driven ReAct Loop) с полноценной локальной веб-консолью управления.

Проект построен вокруг концепции автономного агента, функционирующего в событийно-управляемом цикле размышлений и действий. Система собирает контекст, формирует структурированную цепочку мыслей, исполняет действия через доступные интерфейсы и переходит в режим ожидания до следующего тика или внешнего прерывания.

Фреймворк спроектирован для нативного запуска на хост-машине с гибкой политикой контроля доступа через встроенный Gatekeeper, обеспечивающей безопасное взаимодействие агента с ОС, файловой системой и локальной сетью без обязательной изоляции в Docker.

---

## 🖥 Веб-консоль управления (Web Cockpit)

Начиная с версии `v0.17.0-stable`, JAWL оснащен полноценной локальной веб-панелью управления (доступна по умолчанию на `http://127.0.0.1:8770/`):

* **Живой пульс & активность:** Такты агента в реальном времени, фазы сна/бодрствования, шаги ReAct и визуализация текущих действий.
* **Визуальный редактор параметров:** Управление моделями LLM, пулом API-ключей, температурой, памятью (RAG), лимитами контекста, роем субагентов и паттернами подсознания без ручной правки YAML.
* **Управление множеством интерфейсов:** Гранулярная настройка доступов к ОС (0-3), Telegram (Telethon/Aiogram), GitHub, Email, Браузеру (Playwright), Голосу (STT/TTS), Вебхукам и RSS.
* **Чат с агентом:** Прямой двусторонний диалог с пробуждением агента в реальном времени (CRITICAL events).
* **Менеджер памяти и баз:** Просмотр счетчиков и безопасная очистка SQL, векторных коллекций (Qdrant), кэша моделей эмбеддингов, графа знаний (KuzuDB) и песочницы.
* **Стриминг логов:** Потоковый просмотр журнала `main.log` через Server-Sent Events (SSE) с фильтрацией по уровням.

## 🏗 Ключевые архитектурные решения

### 1. Гибридный Vector-Graph RAG
Подсистема долгосрочной памяти сочетает векторный семантический поиск (Qdrant + FastEmbed) и структурированный граф знаний (KuzuDB). При получении входящих событий оркестратор извлекает сущности из текста, выполняет кросс-резолвинг по обеим базам и формирует сводку фактов и причинно-следственных связей. Это существенно снижает эффект «амнезии» языковых моделей при длительной эксплуатации.

### 2. Фрактальное дерево мыслей (ToT)
Вместо прямого импульсивного выполнения первого сгенерированного действия, агент способен запустить внутреннюю симуляцию сценариев. Модель строит рекурсивное дерево макро-стратегий и микро-сценариев, сопровождая каждую ветку Cost-Benefit анализом (списками плюсов и рисков). Это позволяет оценить последствия решений до их выполнения в реальном окружении.

### 3. Вероятностное мышление через Байесовские гипотезы
Модуль использует формулу Байеса как структурирующий каркас для дедуктивного расследования агента. При возникновении ошибок или неизвестности система формулирует гипотезы, собирает улики через инструменты и математически пересчитывает степень уверенности в каждой гипотезе, защищаясь от неверных выводов через правило Кромвеля.

### 4. Роевая оркестрация (Swarm)
Главный агент, будучи оркестратором, может делегировать трудоёмкие и рутинные задачи фоновым субагентам (`CODER`, `WEB_RESEARCHER`, `ARCHIVIST`, `QA_ENGINEER`, `SYSADMIN`). Субагенты работают в изолированных `Stateless ReAct` циклах на более дешёвых моделях, не имеют доступа к основной памяти и возвращают результат в виде итогового Markdown-отчета.

### 5. Событийно-управляемый Heartbeat
Агент засыпает на заданный интервал, но моментально просыпается при поступлении ивентов через `EventBus`. В зависимости от приоритета события (от `BACKGROUND` до `CRITICAL`) применяется коэффициент ускорения сна, что минимизирует задержку реакции на важные сигналы.

### 6. Безопасная самомодификация (Deploy Sessions)
При наличии прав уровня `OPERATOR` агент может модифицировать исходный код фреймворка. Изменения происходят в рамках деплой-сессии с транзакционным бэкапом Copy-on-Write. Перед коммитом автоматически прогоняются валидатор синтаксиса и тест-пак (`pytest`). При провале тестов система осуществляет автоматический роллбэк.

## 💻 Системные требования

* **Операционная система**: Windows 10/11, Linux (Ubuntu 22.04+), macOS.
* **Версия Python**: Python 3.11 strictly (*бинарные зависимости оптимизированы под 3.11*).
* **CPU**: 2+ ядра (рекомендуется 4+ ядра для локального векторизатора FastEmbed).
* **RAM**:
  * **Минимум**: 4 ГБ RAM + **обязательный файл подкачки (Swap) не менее 2 ГБ**.
  * **Рекомендуется**: 8 ГБ RAM и более.

## 🏗 Архитектура L0 - L3

Система разделена на 4 слоя с четким соблюдением принципа единой ответственности (SRP):

* **L0 (State Layer)**: Пассивные витрины данных (MRU-кэши). Хранят снимки состояния интерфейсов (сообщения, метрики ПК, открытые файлы) без выполнения I/O операций.
* **L1 (Databases Layer)**:
  * *SQL (SQLite)*: Задачи (Eisenhower Matrix), черты характера (Traits), субъекты (Mental States), мотиваторы (Drives), гипотезы (Hypotheses) и логи тиков.
  * *Vector DB (Qdrant + FastEmbed)*: Семантическая память (Knowledge и Thoughts).
  * *Graph DB (KuzuDB)*: Граф знаний и архитектурный граф кода (Code Graph).
* **L2 (Interfaces Layer)**: Плагины взаимодействия с внешним миром (`Host OS`, `Telegram`, `GitHub`, `Email`, `Web Search/Browser/Hooks/RSS`, `Calendar`, `Code Graph`, `Voice`).
* **L3 (Agent Core Layer)**: Вычислительное ядро (`ReactLoop`, `Heartbeat`, `LLMExecutor` с ротацией ключей, `PromptBuilder`, `ContextBuilder`, `SubconsciousOrchestrator`, `SwarmManager`).

## 🚀 Установка и быстрый старт

### 1. Клонирование
```bash
git clone https://github.com/th0r3nt/JAWL.git
cd JAWL
```

### 2. Запуск веб-консоли (Основной режим)

На Windows просто запустите `start.bat` двойным кликом. 

Либо выполните команду в терминале:
```bash
python -m src.web
```
*Консоль автоматически создаст необходимые файлы настроек из шаблонов, поднимет локальный сервер на `http://127.0.0.1:8770/` и откроет браузер.*

### 3. Запуск терминального меню (Headless / CLI-режим)
Если вы работаете на удаленном сервере без графического интерфейса:
```bash
python jawl.py
```
*Загрузчик автоматически развернет виртуальное окружение (venv), установит зависимости и откроет текстовое терминальное меню.*

### 🐧 Запуск на Linux VPS
1. Установите системные зависимости: `sudo apt install -y python3 python3-venv git tmux`
2. Создайте файл подкачки (Swap):
   ```bash
   sudo fallocate -l 2G /swapfile
   sudo chmod 600 /swapfile
   sudo mkswap /swapfile
   sudo swapon /swapfile
   ```
3. Запустите веб-консоль для удаленного доступа:
   ```bash
   python -m src.web --host 0.0.0.0 --port 8770 --token your_secret_token --no-browser
   ```

## 🛡 Безопасность и ограничения песочницы

Модули `sandbox_runner.py` и `_sandbox_guard.py` представляют собой **best-effort барьер внутри одного процесса Python**, а не абсолютную изоляцию уровня ОС.
Для выполнения полностью ненадёжного или сгенерированного сторонними моделями кода запускайте JAWL внутри изолированной виртуальной машины или Docker/Podman контейнера.
