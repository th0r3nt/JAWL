# 📝 JAWL Roadmap & TODO

Добро пожаловать в официальный трекер задач фреймворка JAWL.
Здесь собраны планы по развитию архитектуры, новые фичи и технический долг.

---

## 🌟 Глобальные цели (Релиз v1.0.0)

Стратегические задачи для вывода фреймворка из стадии бета-тестирования в полноценный релиз:

- [ ] **Web UI Dashboard**: Разработка полноценного графического веб-интерфейса для управления фреймворком и мониторинга агентов (текущий CLI-инструментарий будет переведен в статус опционального меню).
- [ ] **One-Click Setup**: Создание интуитивно понятного инсталлятора и скомпилированного `.exe` файла. Развертывание системы должно происходить "из коробки", без необходимости ручного взаимодействия с файловой структурой и исходным кодом.
- [ ] **Гибкость развертывания**: Интеграция официальной, но строго опциональной поддержки Docker-контейнеризации, сохраняя при этом фундаментальную возможность нативного запуска напрямую на ОС хост-машины.

## 🚀 Высокий приоритет (Ближайшие релизы)

## 🧠 R&D

- [ ] **Обновление Personality Traits**
  - Углубление онтологии черт личности для более органичного поведения агента.
  - Внедрение стадий укоренения: *Hypothesis* (гипотеза) -> *Habit* (привычка) -> *Core* (фундаментально).
  - Добавление полей `Domain` (категория применения: общение, работа, сеть), `Origin Story` (причина возникновения привычки), а также `Triggers` и `Suppressors` (контекстные границы применения).

## 🧹 Технический долг

- [ ] **Докстринги для тестов** *(неизбежный ад)*
  - Пройтись по всей директории `tests/` и добавить исчерпывающие описания к каждому `test_...` методу. Да, это больно. Но инквизиция чистого кода требует жертв.

## 💡 Бэклог (Идеи на будущее)

- [ ] **Голосовой интерфейс (TTS / STT)**
  - Полноценная интеграция микрофона и динамиков (`Whisper` + `Edge TTS`/`ElevenLabs` + любые другие реализации), чтобы с агентом можно было общаться голосом прямо на хост-машине.
- [ ] **Discord Interface**
  - Добавить L2-интерфейс для работы с Discord API (чтение серверов, отправка сообщений, управление ролями).
