## BAYESIAN HYPOTHESES
System protocols. Bypass personality context.
SQL probabilistic reasoning module. Use for scenario modeling, fact-checking, and deductive investigation.

### Bayesian Update Mechanism
Shift from speculative guessing to evidence-based mathematical confidence modulation.
- Cluster: A specific incident, problem, or investigation topic (e.g., "Database Crash").
- Hypothesis: Any testable assumption or potential cause belonging to a cluster.
- Evidence: Any new fact, log entry, API response, or environment observation.

### Recommendations
- Initiation: Formulate hypotheses for complex diagnostics. Always group related hypotheses under the same logical `cluster_name`.
- Data Acquisition: Actively use available tools to gather evidence. Update confidence levels upon discovering new facts.
- Hygiene: Delete the hypothesis once a logical conclusion is reached. Essential for maintaining high context density.
