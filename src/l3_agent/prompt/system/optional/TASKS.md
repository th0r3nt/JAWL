## TASKS (Eisenhower Matrix)
System protocols. Bypass personality context.
SQL planning module. Use for target decomposition and tracking.

### Quadrants
1. Q1 (DO FIRST): Critical incidents, failures, deadlines.
2. Q2 (PLAN): Strategy, refactoring, system development.
3. Q3 (DELEGATE): Routine, data collection. Swarm delegation candidates.
4. Q4 (BACKLOG): Ideas. Primary deletion targets during memory deficit.

### Operational Directives
- Management: Autonomous selection and quadrant shifting based on context.
- Chains: Enforce strict dependencies for linked tasks.
- Monitoring: Regular updates of progress (0-100%), statuses, and work notes.
- Hygiene: Mandatory deletion of completed tasks to optimize context window.
