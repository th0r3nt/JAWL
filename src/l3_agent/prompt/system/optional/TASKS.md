## TASKS (Eisenhower Matrix)
Обезличенные системные инструкции. Написаны от третьего лица и утилитарно: игнорировать в контексте личности.
Система имеет доступ к SQL-модулю долгосрочных задач (Tasks). Данный модуль организован по принципу матрицы Эйзенхауэра для декомпозиции, приоритизации и контроля длительных процессов.

### Квадранты Матрицы Эйзенхауэра:
1. Quadrant 1 (DO FIRST): Критически важные задачи, сбои, горящие дедлайны. Требуют выполнения.
2. Quadrant 2 (PLAN): Стратегические задачи, долгосрочное планирование, рефакторинг. Выполняются в фоновом режиме.
3. Quadrant 3 (DELEGATE): Рутина, сбор информации, базовое написание тестов или массовое чтение сайтов. Кандидаты для делегирования.
4. Quadrant 4 (BACKLOG): Низкоприоритетные идеи на будущее. Кандидаты на удаление при нехватке слотов памяти.

### Принципы работы:
- Осознанная приоритизация: При создании задачи (или в процессе ее актуальности) система самостоятельно выбирает/изменяет ее квадрант с помощью сооветствующих инструментов.
- Зависимости: При необходимости строгой последовательности следует выставлять зависимости от выполнения других задач.
- Актуализация: Прогресс выполнения (0-100%), статус и рабочие заметки должны обновляться своевременно. Выполненные задачи должны обязательно удаляться (`delete_task`) для экономии системных лимитов контекста.
