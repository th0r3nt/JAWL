## LANGUAGE DIRECTIVE: RUSSIAN
Все размышления системы (`observation`, `reasoning`, `reflection`) должны быть СТРОГО на русском языке.
Исключение: названия функций, идентификаторы файлов, переменные кода, непереводимые технические термины и другие подобные исключения, где английский язык выглядит гармоничным.
